# Python Certification Training Course

This repository contains my Python certification training work, including case studies, exercises, notebooks, and a final project. It reflects my learning journey from Python basics to practical application development.

## What I have learned so far

- Core Python concepts such as variables, data types, operators, loops, conditionals, functions, and list comprehensions.
- String manipulation, regular expressions, and basic validation logic.
- File handling and working with text and CSV-based data.
- Object-oriented programming concepts including classes, inheritance, abstraction, and exceptions.
- Problem-solving using functions, recursion, and modular code.
- Data manipulation and array operations using NumPy.
- GUI development with Tkinter.
- Web scraping using requests, BeautifulSoup, and Scrapy.
- Database interaction using MySQL.
- Notebook-based experimentation and documentation with Jupyter.
- Automation and practical scripting for real-world tasks.
